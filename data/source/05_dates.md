| You will visit the Food Court several times per game, where you can date and converse with the main and guest characters. /  / Dates and Spice Levels: / The first time you visit a character in a run, you will choose an activity and go on a date with that character. Activities have different spice levels, indicated by chili peppers, that determine how platonic or romantic the Date Ending text will be: / Level 0 - Platonic / Level 1 - Romantic / Level 2 - Suggestive / Level 3 - Explicit /  / Note: There are 2 date variations for each non-Plotline activity. The date variation you get is random. /  / Additionally, once you successfully complete a plotline, a new date activity will become available for the Plotline's featured character (whichever character you had to ask to the Spooky Con afterparty to experience the Ending). The activity will have an open scroll icon next to it. If chosen, you are guaranteed the first event of it's associated plotline next turn. /  / Main Characters: / These characters are seated in pairs across three tables. Visit the table and choose which character you'd like to interact with. /  / Guest Characters: / These characters can be called if you sit at the table with the yellow tablecloth. Some characters need to be unlocked. / |  |  |  |  |  |  |  |
