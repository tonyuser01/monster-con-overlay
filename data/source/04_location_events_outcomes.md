| Exchange Events: / Exchange events are zero-sum events where a stat is always gained and another stat is always lost in the same amount. You will gain the stat associated with the outcome you chose, and lose the stat associated with the outcome you didn't choose. /  / Check Events: / Check events are events, usually seen in Plotlines, where each outcome is associated with a stat, and those stat levels are compared against each other. If your stat level associated with the outcome you chose is higher than the stat level associated with the outcome you didn't choose, you will succeed and gain stats. If your stat level associated with the outcome you chose is lower than the stat level associated with the outcome you didn't choose, you will fail and lose stats. If your stat level associated with the outcome you chose is tied with the stat level associated with the outcome you didn't choose, the game will flip a coin to decide the result. /  / However, there are also thresholds for success and failure - if your stat level is below 10 you will fail even if it is higher than than the outcome's stat level, or if your stat level is 10 or greater you will succeed even though it is lower than the other outcome's stat level. |  |  |  |  |  |  |  | Associated Stat | Associated Stat |  |  |  | Associated Stat | Associated Stat |  |  |  | Associated Stat | Associated Stat |  |  |  | Associated Stat | Associated Stat |  |  |  | Associated Stat |  | Associated Stat |  | Associated Stat |  | Associated Stat |  |  |  |  | Associated Stat |  | Associated Stat |  | Associated Stat |  | Associated Stat |  |
