# Plotline Endings

| Plotline Endings: Explained |  |  |  |  |  |  |  |  |
| Plotline endings occur when you successfully complete a plotline and ask it's associated character to the Spooky Con afterparty. There are currently 16 Plotlines in the game, some with multiple Ending variations. Plotlines feature a series of story-connected events, with a mixture of exchange events and check events. Some Plotlines need to be unlocked, and some Plotlines require specific actions to trigger them. /  / If you fail a Plotline event, you fail the Plotline and will not be eligible for it's associated ending. /  / Note: Plotlines are not available in short games. |  |  |  |  |  |  |  |  |
